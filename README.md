# Robotic Perception
[![CodeFactor](https://www.codefactor.io/repository/github/nykabhishek/robot-localization-algorithms/badge)](https://www.codefactor.io/repository/github/nykabhishek/robot-localization-algorithms)

Jupyter Notebook implementation of Robot perception algorithms.

Algorithms include:
  - `Grid-based (histogram) Bayes Localization` - [monte_carlo_localization.ipynb](./monte_carlo_localization.ipynb)
  - `Kalman Filter` - [kalman_filter/KF.ipynb](./kalman_filter/KF.ipynb)
  - `Extended Kalman filter` - [ekf_sensor_fusion/EKF.ipynb](./ekf_sensor_fusion/EKF.ipynb)
